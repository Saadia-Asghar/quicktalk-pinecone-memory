04 / 17
Isolation model

Shared platform. No shared customer memory.

Boundary 1 · Organization

Every Pinecone operation uses an organization-derived namespace.

Boundary 2 · Customer

Mem0 user ID hashes organization + normalized mobile number.

Boundary 3 · Authority

Flask rejects claimed and requested organization mismatches.

3×

Independent scope checks before a memory can become an answer.

Rejected

10 / 17
Version safety

Pinecone finds candidates. SQL decides what is allowed.

Edit

Create a newer active version.

Disable / delete

Authoritative status changes immediately.

Retrieve

Reject stale or superseded vector candidates.

Truth ≠ similarity

Semantic relevance alone is never enough for governed knowledge.

11 / 17
Tone tool

Humanized voice is separate from factual memory.

Learns

Politeness, reply length and language-style patterns.

Never learns

Customer facts, agent mistakes, promises or unsupported claims.

Always preserves

Prices, dates, restrictions, currencies and uncertainty.

Safe failure

If Groq times out, return the grounded answer unchanged.
